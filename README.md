# DasDigitaleMomentum/.github

Organisation profile of [Das Digitale Momentum](https://www.das-digitale-momentum.de/en/) on GitHub. `profile/README.md` is shown on https://github.com/DasDigitaleMomentum.

The header banners (`profile/assets/header-{light,dark}.svg`) and the avatar are rendered from the DDM design system: signet from the website's logo SVG, Montserrat 700 as paths (SIL Open Font License), colours navy `#0a1628`, logo blue `#2039c9`, orange `#ff3300` / `#c92800`.
